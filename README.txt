Daily Quotes - Android (Java) - Gradle project

Included:
- Full Gradle project ready to open in Android Studio (root + app)
- MainActivity.java attempts to load quotes from QUOTES_URL and falls back to assets/quotes.json
- Uses AdMob TEST IDs so ads will show in test mode. Replace with your own AdMob IDs before publishing.

How to use:
1. Download the zip from the link provided.
2. Unzip and open the project folder in Android Studio.
3. Let Gradle sync. Build & Run on a device/emulator.
4. Optional: Host app/src/main/assets/quotes.json on GitHub Gist/raw URL and update QUOTES_URL in MainActivity.java to point to it.

Notes:
- Do NOT use the test AdMob IDs in production. Replace them with your AdMob account IDs when ready to publish.
